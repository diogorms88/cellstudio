# bodies – arquivos 3D

- Carrocerias e peças soltas (`.hsf`, `.stl`, `.obj`, `.usdz`), direto aqui ou numa pasta por modelo.
- A biblioteca de modelos do DXQ (`3DObjects`, com `Robots/` e `Tools/`) também pode ficar aqui
  (`bodies/3DObjects/`): baixada no app, passa a ser usada para desenhar os robôs.

No app: **Download** ▸ Arquivos 3D ▸ Baixar ▸ *Importar* (carroceria) ou *Usar como modelos 3D* (3DObjects).
Arquivos acima de 100 MB não entram no GitHub.
